# Spiral coach - parent key

This key applies only to the original rehearsal. Do not use it as the current Schoology answer key. Printed choices retain this order; on-screen choices shuffle.

1. **A: “Hold the fabric flat,” Zoe said.** - Dialogue is what a character says aloud. A sound, thought or action alone is not speech.
2. **B: “I found the spool,” Mira said.** - The spoken statement ends with a comma inside the closing quotation mark; the dialogue tag continues the sentence.
3. **C: “Can you help me?” Zoe asked.** - The question mark belongs inside the quotation marks. The tag continues with lowercase asked; the name remains capitalized.
4. **D: “The seam is straight.” Mira smiled.** - Smiled describes an action, not a speech tag. End the spoken sentence, then start a new action sentence.
5. **A: I steadied the fabric while Mira turned the wheel.** - I must consistently refer to Zoe. Narration can report what Zoe observes, thinks and does, not directly know Mira’s thoughts.
6. **B: Change the sewing task into winning a swimming race.** - A point-of-view rewrite changes the lens, not the main events or their order.
7. **C: Add meaningful spoken words that fit the event, plus action and thoughts.** - Sound effects do not fulfill a dialogue criterion. Speech should reveal character or move the scene along.
8. **D: Keep the experiment’s steps, narrate one partner’s experience, and add fitting spoken exchanges.** - The same narrator/speech/action distinctions apply; the setting and events change.

A sound effect alone is not dialogue. Pronoun replacement alone is weak development. Review speech, action and inner thought separately. Require first draft before showing examples; give specific feedback and a new application for each gap. Preserve first writing and score. Supported revision is separate evidence.
